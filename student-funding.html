ARQWELL / FUTURE DATABASE CONNECTIONS

Student funding search sources.

ARQWELL can add live feeds after API access, licensing and source verification. Do not submit API keys through the public student inquiry form.

CareerOneStop Scholarship Finder

U.S. Department of Labor scholarship directory with filters for high school, associate degrees, fields, award types and location. A public search portal is available; API availability for scholarship records needs confirmation before integration.

Explore directory ↗

ScholarshipOwl for Business

Documented authenticated scholarship API, primarily for organizations administering their own scholarships and applicants. It is not confirmed as a general third-party scholarship search feed.

Review API documentation ↗

College Scorecard API

U.S. Department of Education API for college programs, costs and outcomes—not individual scholarship opportunities. Useful for identifying community colleges and AEC-related study options.

Review college data ↗

Scholarship America & Colorado COSI

Strong sources for curated scholarships and student aid, but a public general-purpose scholarship-listing API has not been confirmed. Link to official applications or explore partnership/data-sharing permission.
